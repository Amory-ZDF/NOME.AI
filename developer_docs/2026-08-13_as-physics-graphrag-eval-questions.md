# AS 物理 GraphRAG — 分层评测题集

> 用途:验证向量化知识图谱在"简单题之外"的表现,尤其是多跳推理、跨章连接、大概念上溯、选工具决策。
> 日期:2026-08-13
> 配套:本体 `ontology.json`、图 `as_physics_graph.json`(若已生成)

---

## 0. 为什么这套题这样设计

向量化 = 相似度检索,擅长**单节点、单事实**的简单题(定义、公式、一对概念区别)。这正是"简单验证效果还可以"的原因。

GraphRAG 的增量价值在**多跳**——答案需要沿边走 2-5 步、跨章节、上溯大概念、或在多个等价方法里选一个。本评测按"图能力"分层,每题的标注告诉你它踩了哪类边/大概念,这样答案错了你能定位是**图缺边**还是**检索/生成层**的问题。

**标注图例(对应 ontology.json 的边类型):**

| 缩写 | 含义 |
|---|---|
| PRE | PREREQUISITE_OF 前置链 |
| REQ | REQUIRES_SKILL 需要技能 |
| BEL | BELONGS_TO 属于章节 |
| CON | CONTRASTED_WITH 对立辨析对 |
| EXE | EXEMPLIFIES 上溯大概念 |
| ERT | EQUIVALENT_ROUTE 选工具 |
| BIG-宏观 | Macro-micro correspondence 大概念 |
| BIG-守恒 | Conservation laws |
| BIG-能量 | Energy & energy transfer |
| BIG-波 | Waves transfer energy |
| BIG-建模 | Modeling & idealization |
| BIG-测量 | Measurement & uncertainty |

**判读准则:**
- 答案**正确且完整** → 图边 + 检索 + 生成三层都通。
- 答案**方向对但缺关键一步**(如漏了"无外力"限定、漏了某个对立面)→ 大概率是检索没召回那条边,或生成层没把边展开。查图里那条边在不在。
- 答案**完全跑偏/编造** → 要么图缺该节点,要么向量检索把相似但无关的节点排前面了(向量相似度 ≠ 逻辑相关)。
- **陷阱题答错**(该拒绝却编造)→ 边界控制问题,向量检索对 OOS(out-of-scope)问题没有"没有答案"这个态,需要补一个"置信度阈值 + 显式'不在 AS 范围'"的兜底。

## 2. 中等题(2-3 跳,跨章或踩一条大概念线)

### M1. 灯丝灯泡的 I-V 图是弯曲的,而欧姆电阻的是过原点的直线。从原子层面解释这个区别。
- 踩边:BEL(→Electricity)+ BIG-宏观(I=Anvq、电阻率随温度、原子振动加剧)
- 好答案应走:Ohm's law(恒温条件)→ 灯丝升温 → 原子振动加剧 → 电子碰撞更频繁 → 漂移受阻 → 电阻增大 → 图弯曲。
- 测什么:宏观-微观对应是否真的连上了,而不是只背"温度升电阻升"。

### M2. 电池接上负载后,端电压为什么低于它的 e.m.f.?丢失的电压去了哪里?
- 踩边:CON(emf ↔ terminal p.d.)+ BEL(→D.C. Circuits)
- 好答案应走:ε = I(R+r)、V_terminal = IR、lost volts v = Ir,内阻分压。
- 测什么:对立辨析对是否被召回,以及"lost volts"这个概念的归属。

### M3. 汽车在平路上匀速行驶,发动机仍在做功。说明此时发动机力等于什么,以及功率如何计算。
- 踩边:PRE/跨章(Newton's 1st law → work → power)+ CON(匀速 vs 加速)
- 好答案应走:匀速 → 合力为零 → 引擎力 = 摩擦力 → P = Fv。
- 测什么:把"匀速"翻译成"合力为零"这层逻辑,不是公式检索。

### M4. 描述跳伞者如何达到终端速度,从力的角度说明。
- 踩边:PRE(Newton's 2nd law → air resistance → resultant force)+ BEL(→Dynamics)
- 好答案应走:重力恒定、空气阻力随速度增大 → 合力渐减 → 加速度渐减 → 阻力=重力时合力为零 → 匀速。
- 测什么:动态平衡的过程推理。

### M5. 为什么纵波不能被偏振?这如何说明电磁波是横波?
- 踩边:CON(transverse ↔ longitudinal)+ BEL(→Waves)
- 好答案应走:偏振只能发生在振动⊥传播方向的波 → 纵波振动∥传播 → 无法偏振 → EM 波可偏振 → 证明其横波性。
- 测什么:对立对 + 用它做证据链。

### M6. 石头从桥上落下,分别用 SUVAT 和能量守恒两种方法求落地速度,并解释为什么结果一致。
- 踩边:ERT(SUVAT ↔ 能量法)+ BIG-能量 + BIG-建模
- 好答案应走:v² = u²+2as 与 mgh=½mv² 两种路径,一个算运动学、一个算能量,结果同为 v=√(2gh)。
- 测什么:**选工具边是否真的存在**。这是纯向量检索最容易答糊的题(两个方法分散在不同章节,相似度都不高)。

### M7. 为什么液体压强随深度增加?它如何产生向上的浮力?
- 踩边:PRE(Δp=ρgΔh → pressure difference → upthrust/Archimedes)
- 好答案应走:p=ρgh → 底部压强大 → 底部向上的力 > 顶部向下的力 → 合力向上 = 浮力。
- 测什么:从压强差到浮力的两步因果链。

### M8. 用位移-时间图说明如何求瞬时速度,它和平均速度有何不同?
- 踩边:REQ(instantaneous velocity → 画切线技能)+ CON(瞬时 vs 平均)
- 好答案应走:切线斜率 = 瞬时速度;割线斜率 = 平均速度。
- 测什么:技能边(画切线)+ 图线几何解释。

## 3. 复杂题(4+ 跳,跨章 + 上溯大概念 + 选工具)

### C1. 完全非弹性碰撞中,动量守恒但动能不守恒。'丢失'的动能去了哪里?为什么能量都损失了动量反而还守恒?
- 踩边:CON(elastic ↔ inelastic)+ BIG-守恒 + BIG-能量 + BIG-宏观
- 好答案应走:动量守恒(无外力,封闭系统)→ 动能损失 → 转化为内能(形变/热/声)→ 微观上是分子动能增加;动量是矢量且无外力时严格守恒,动能是标量且可转化为其他形式。
- 测什么:两个守恒定律的**不对称性**是否被理解——这是大概念层的核心洞察,向量检索几乎不可能答全。

### C2. 解释为什么基尔霍夫两条定律本质上是电荷守恒和能量守恒,并用它们推导串联和并联电阻的规则。
- 踩边:EXE(Kirchhoff → BIG-守恒)+ PRE(→串并联规则)
- 好答案应走:第一定律(结点电流和为零)= 电荷守恒;第二定律(回路电压和为零)= 能量守恒;串联 R=R1+R2、并联 1/R=1/R1+1/R2 由此导出。
- 测什么:**EXEMPLIFIES 上溯是否真的发生**——弱的是"电路",上溯到"守恒律"家族。这是我们标过的最值钱的一条线。

### C3. 质子和 α 粒子从静止经相同的电势差 V 加速。比较它们的末速度和末动量,并说明 specific charge 在其中扮演的角色。
- 踩边:PRE(比荷)+ 跨章(Electricity 的 qV → Particle Physics)+ BEL
- 好答案应走:能量增益 qV → ½mv²=qV → v=√(2qV/m)=√(2·比荷·V);α(2e, 4u)比荷 = e/2u,质子 = e/u,质子比荷 2 倍 → 质子末速 √2 倍;动量 p=mv=√(2mqV),α 动量更大。
- 测什么:4+ 跳的跨章链(电学能量 → 粒子性质 → 比荷 → 动量),是整套里最难的之一。

### C4. 描述测量金属丝 Young 模量的实验:测什么量、用什么仪器、应力-应变图斜率如何给 E,以及主要不确定度如何合并。
- 踩边:REQ(实验技能)+ BIG-测量 + PRE(stress/strain → Young modulus)
- 好答案应走:直径(千分尺、3 处取平均 → A=πd²/4)、原长 L(米尺)、伸长 x(标记+尺)、F=mg(砝码);画 σ-ε 图,斜率 = E;直径平方 → 百分不确定度翻倍。
- 测什么:测量大概念 + 技能边 + 不确定度传播,一次踩三块。

### C5. 两端固定的弦被拨动。解释驻波的形成、节点/腹点间距为何是 λ/2、以及基频如何依赖张力和长度。
- 踩边:PRE(progressive → stationary wave)+ CON(node ↔ antinode)+ BEL
- 好答案应走:两列同频反向行波叠加 → 驻波;节点相消、腹点相长,相邻节点间距 λ/2;f=(1/2L)√(T/μ)。
- 测什么:波 → 叠加的多跳链 + 对立对。

### C6. 解释声源靠近观察者时的多普勒效应,说明 f_o = f_s·v/(v−v_s) 中符号约定为何导致频率升高,远离时又怎样。
- 踩边:BEL(→Waves)+ CON(靠近 ↔ 远离)
- 好答案应走:源靠近 → 波前压缩 → 波长变短 → 频率升高;分母减 v_s → 分母变小 → f_o 变大。
- 测什么:公式符号约定的物理意义,而非死记。

### C7. 单摆摆到最低点时速度最大。解释全程的能量转化,并说明为什么绳的张力不做功(尽管有力作用)。
- 踩边:BIG-能量 + CON/跨章(work W=Fd cosθ → tension ⊥ displacement)
- 好答案应走:GPE↔KE 转化;最低点速度最大 = KE 最大;张力始终沿径向、垂直于速度 → cos90°=0 → W=0。
- 测什么:能量大概念 + "力做功需沿位移分量"的微妙点。

### C8. 区分 precision 与 accuracy,解释为什么乘法/除法要加百分不确定度、加/减法要加绝对不确定度,并用它说明为什么测量更大的量能减小其分数不确定度。
- 踩边:CON(precision ↔ accuracy)+ BIG-测量
- 好答案应走:precision=离散度、accuracy=离真值;Δ(A·B)/(A·B)≈ΔA/A+ΔB/B;量更大 → 分数不确定度更小。
- 测什么:测量大概念 + 不确定度传播规则的理解深度。

## 4. 陷阱/边界题(测图的诚实度与置信度)

### T1. A-Level 物理中,电容器储存能量的公式是什么?
- 预期:E = ½CV² 是 **A2 内容**,不在 AS 笔记里。
- 好的行为:明确说"超出 AS-Level 范围"(或说明属于 A2 电场/电容章节)。
- 差的信号:瞎编一个公式,或用 AS 里的"弹性应变能 ½Fx"张冠李戴。
- 测什么:OOS 边界是否诚实。

### T2. 只要系统是闭合的,动量就永远守恒,即使有外力作用?
- 假前提陷阱。"闭合"和"无外力"是两回事,动量守恒条件是**无外力(或合外力为零)**。
- 好的行为:指出前提错误,纠正为"无合外力时动量守恒"。
- 测什么:是否抓得住守恒条件的限定词。

### T3. 电阻率和电阻有什么区别?
- 踩边:CON(resistivity ↔ resistance)+ BIG-宏观
- 好的行为:ρ=RA/L 是材料属性(与尺寸无关),R 是具体元件属性(与尺寸有关)。
- 测什么:对立辨析对的精准度——这俩名字像、学生极常混。

### T4. 学生说"弹性碰撞和非弹性碰撞的区别只在于是否粘在一起"。对吗?
- 陷阱:"粘在一起"是**完全非弹性**的充分条件,但弹性/非弹性的本质判据是**动能是否守恒**。
- 好的行为:纠正判据,指出粘合只是非弹性的极端情形。
- 测什么:概念的精确判据,而非表面特征。

### T5. 为什么点波源的强度随距离增大而减小?它和振幅是什么关系?
- 踩边:BEL(→Waves)+ PRE(intensity → I=P/A → I∝A²)
- 好的行为:能量分散到更大的球面 → I=P/(4πr²);I∝A²。
- 测什么:中等偏难,顺带看 I∝A² 是否被召回(它在笔记里只有一句)。

## 5. 使用建议

1. **先跑基线 B1-B4**,确认没退化。
2. **中等 M1-M8 逐题过**,每题记录:答对 / 方向对但缺步 / 跑偏。跑偏的题去查图里对应边在不在(不在=图缺边;在=检索没召回)。
3. **复杂 C1-C8** 是重点,尤其 C1(守恒不对称)、C2(基尔霍夫=守恒)、C3(质子 vs α)三题——它们最能区分"真多跳"和"向量相似度凑答案"。
4. **陷阱 T1-T5** 单独看,重点不是答对,是**该拒绝时拒不拒绝**。
5. 建议给每题记一个 1-3 分(1=错,2=对但不完整,3=对且完整),最后按 tier 汇总,定位是哪类边/大概念系统性缺失。

## 6. 已知的"向量化"风险(供排查参考)

- **向量相似 ≠ 逻辑相关**:C1/C2 的正确答案节点和问题词面相似度可能很低,纯向量检索会召回一堆"动量""能量"的高频节点,但拼不出"不对称性""上溯到守恒律"这层。
- **OOS 无答案态**:T1 这类问题,向量检索会硬给一个最近邻,而不是说"没有"。需要显式的置信度阈值 + "不在 AS 范围"兜底。
- **多跳缺失**:如果只向量化了节点文本、没把边也做成可遍历结构,那 PRE/CON/EXE/ERT 这四条边会系统性失效,表现为"中等题里凡是跨章节的都不会"。
